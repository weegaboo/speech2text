# Локальная проверка — 22 октября 2026

Окружение: Mac Apple M5, 24 ГБ памяти, Python 3.11.6. Обе модели настроены на 4 потока CPU. Зависимости закреплены в `uv.lock`. Проверки проводились на общедоступных и синтетических записях; личные записи пользователя пока не использовались.

## Автоматические проверки

`uv run pytest -q`: **28 passed**. `uv run ruff check src tests scripts`: ошибок нет.

Проверены допустимые сочетания модели и языка, обход папок и коллизии имён, повреждённые файлы, сохранение прогресса, повторный запуск, изменённый исходник/настройки, защита пользовательских текстов, атомарная публикация, восстановление после прерывания публикации, блокировка параллельных запусков в одной папке, контрольные суммы и отсутствие автоматической загрузки модели.

Отдельные проверки стыков покрывают совпадающие слова в перекрытии, смещение временных меток в обе стороны, неточные/нулевые метки Whisper и настоящие повторы речи. Проверка декодера подтверждает точное совпадение сэмплов после возобновления WAV. Дополнительный прогон на MP3, M4A/AAC и Opus также подтвердил посэмпловое совпадение возобновлённого декодирования.

## Реальное распознавание

- Русский пример `example.wav` из репозитория GigaAM: обе модели сформировали текст. Фрагмент длится 11,29 с.
- Английский `samples/jfk.wav` из whisper.cpp: Whisper сформировал английский текст без перевода, включая обе части «ask not … ask what …».
- Синтетическая русская речь системного голоса Milena, повторённая 6 раз без добавления пауз: 67,221 с. Она специально пересекает вынужденные границы фрагментов.
- WAV, MP3, M4A/AAC, OGG/Opus, Opus и FLAC обработаны в одной очереди GigaAM. Сохранены вложенные папки и разные результаты для совпадающих основ имён. Один повреждённый MP3 не остановил остальные: 6 успешных файлов, 1 ошибка, код завершения 1.

Результат сравнения на синтетической записи после исправления сборки стыков:

| Модель | Полное время команды | WER без унификации чисел |
| --- | ---: | ---: |
| GigaAM-v3 `v3_e2e_rnnt` | 3,83 с | 6,67% |
| Whisper large-v3 / whisper.cpp | 62,65 с | 4,00% |

Время включает запуск процесса, проверку файлов модели, загрузку и распознавание. Это один прогон с прогретым файловым кешем, а не гарантия скорости на других записях. Синтетическая речь короткая, чистая и повторяющаяся: по этим цифрам нельзя выбирать лучшую модель для реальных голосовых.

В данном тесте все отличия WER обусловлены записью времени: эталон содержит «десять часов», модели выдают `10 часов` и `10:00`. После явной унификации именно этих форм WER обеих моделей равен нулю. Установленные на этапе разработки дубли на стыках устранены на этой записи. В общем случае ошибки распознавания и стыков остаются возможными.

Скрипт сравнения: `scripts/benchmark.py`. Локальный отчёт этого прогона: `test-results/benchmark-final/report.json`; временные аудио и результаты не включены в Git.

## Остановка и восстановление

На реальном процессе GigaAM отправлен SIGINT после первого сохранённого фрагмента. Проверены код 130, отсутствие преждевременно опубликованного `.txt` и наличие прогресса в SQLite.

Повтор **той же команды с `--overwrite`** продолжил с 22,0 с. Полученный файл побайтово совпал с результатом непрерывного запуска. Информация о словах на стыке восстановлена из базы.

## Длинный файл и память

- Декодирование трёхчасового FLAC без накопления фрагментов: 491 фрагмент, максимум 23,2 с аудио в одном буфере, около 45 МБ peak RSS процесса проверки декодера.
- Полный запуск утилиты на трёхчасовой тишине с реальным Silero VAD: 30,04 с полного времени, около 260 МБ peak RSS по `/usr/bin/time -l`, пустой `.txt`, код 0. ASR-модель при отсутствии речи не загружалась.

Эти проверки подтверждают ограниченный аудиобуфер и обработку длительной тишины. Они не являются измерением скорости распознавания трёх часов речи. Память загруженной ASR-модели добавляется отдельно.

На отдельном прогоне синтетической речи длиной 11,2 с снималась сумма RSS процесса утилиты и дочерних процессов с интервалом около 0,1 с: максимум 1982 МиБ для GigaAM и 3942 МиБ для Whisper. Это приближённая сумма RSS, которая может учитывать общие страницы несколько раз и пропустить краткий пик; она не равна точному объёму физической памяти. Локальный отчёт: `test-results/memory/report.json`.

## CPU и офлайн

GigaAM загружается с `device="cpu"`, FP32; проверяется размещение всех параметров на CPU. Silero использует ONNX CPUExecutionProvider. whisper.cpp собран без Metal, CUDA, Vulkan и Core ML; `use_gpu=false`, переменные ANEForge удаляются внутри native-процесса. В журнале Whisper подтверждены единственный CPU backend и `use gpu = 0`.

GigaAM и Silero успешно обработали запись при программном запрете `socket.connect` и `socket.create_connection` в Python. Это проверка приложения, а не блокировка сети всей операционной системы. Whisper получает уже загруженные локальные веса и работает через stdin/stdout, без HTTP-сервера.

`speech2text doctor` подтвердил наличие FFmpeg/ffprobe и корректные контрольные суммы обеих установленных моделей. Собран Python wheel; в него включены исходники native-процесса и CMake-файл.
