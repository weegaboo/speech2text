# speech2text

Программа для Mac, которая превращает аудиозаписи в текст:

- один аудиофайл → один файл `.txt`;
- папка с аудио → папка с текстами.

Работает локально, только на процессоре (CPU). Интернет нужен для установки и скачивания моделей. Сами записи никуда не отправляются.

## Установка

Установка выполняется один раз. Если программа и модели уже установлены, переходите к разделу «Использование».

### 1. Подготовьте инструменты

Откройте приложение **Терминал** на Mac и выполните:

```bash
xcode-select --install
```

Дождитесь завершения установки в появившемся окне. Если инструменты уже установлены, переходите дальше.

Понадобится **Homebrew**. Если команды `brew` ещё нет, установите его по инструкции на [brew.sh](https://brew.sh/) и выполните шаги из раздела **Next steps**, которые появятся после установки.

Затем выполните:

```bash
brew install uv ffmpeg cmake
```

### 2. Установите программу

Скачайте или скопируйте папку проекта `speech2text` на Mac. Перейдите в неё, подставив свой путь:

```bash
cd "/путь/к/speech2text"
sh scripts/setup.sh
```

Скрипт подготовит Python и установит необходимые библиотеки. Отдельно устанавливать Python не нужно.

**Все дальнейшие команды выполняйте из этой папки.**

### 3. Скачайте нужные модели

Для русского языка можно начать с GigaAM:

```bash
uv run speech2text models download --model gigaam-v3
```

Для английского или распознавания русского через Whisper:

```bash
uv run speech2text models download --model whisper-large-v3
```

Можно установить обе модели. GigaAM занимает около 450 МБ, Whisper — 3,1 ГБ; для самой программы потребуется дополнительное место. Загрузка и подготовка Whisper могут занять несколько минут. Дождитесь сообщения о готовности.

Проверить установку:

```bash
uv run speech2text doctor
```

Нужная модель должна иметь статус «готова». Вторую модель устанавливать необязательно.

## Использование

В примерах заменяйте пути на свои. Кавычки позволяют использовать пробелы в именах файлов и папок. Путь также можно вставить, перетащив файл или папку из Finder в окно Терминала.

### Один файл на русском

```bash
uv run speech2text "/путь/голосовое.m4a"
```

По умолчанию используются **GigaAM** и **русский язык**. Рядом с аудио появится `голосовое.txt`.

### Папка с записями

```bash
uv run speech2text "/путь/Записи"
```

Рядом появится папка `Записи_text`. В ней будет отдельный `.txt` для каждой записи.

Чтобы обработать также вложенные папки, добавьте `--recursive`:

```bash
uv run speech2text "/путь/Записи" --recursive
```

Структура вложенных папок сохранится в результатах.

### Выбор модели и языка

| Модель | Значение `--model` | Языки |
| --- | --- | --- |
| GigaAM-v3 (`v3_e2e_rnnt`) | `gigaam-v3` | Русский: `ru` |
| Whisper large-v3 через whisper.cpp | `whisper-large-v3` | Русский: `ru`, английский: `en` |

Русский через Whisper:

```bash
uv run speech2text "/путь/голосовое.m4a" --model whisper-large-v3 --language ru
```

Английский через Whisper:

```bash
uv run speech2text "/путь/recording.mp3" --model whisper-large-v3 --language en
```

Эти же параметры работают для папок. Язык задаётся для всех записей в текущем запуске. Для английского обязательно выбирайте Whisper: GigaAM поддерживает только русский. Текст сохраняется на языке записи, без перевода.

### Своя папка для результатов

```bash
uv run speech2text "/путь/Записи" --recursive --output "/путь/Тексты"
```

`--output` задаёт папку, даже если распознаётся один файл. Для сравнения двух моделей указывайте разные папки результатов.

## Остановка и повторный запуск

Для остановки нажмите **Ctrl+C**. Чтобы продолжить, повторите ту же команду: программа использует сохранённый прогресс.

Готовые результаты повторно не обрабатываются, если исходники и настройки не изменились. Существующие тексты не перезаписываются автоматически. Чтобы заново распознать завершённый файл и заменить его текст, добавьте `--overwrite`:

```bash
uv run speech2text "/путь/голосовое.m4a" --overwrite
```

В папке результатов находится скрытая папка `.speech2text` с прогрессом и журналом ошибок. Сохраняйте её, пока нужна возможность продолжить обработку.

## Что полезно знать

- Поддерживаются MP3, M4A, WAV, OGG, Opus, FLAC и другие распространённые аудиоформаты.
- Одиночный аудиофайл можно передать без расширения, например экспорт из мессенджера с именем `audio`.
- Длинные записи обрабатываются частями. Готовый `.txt` появляется после завершения всей записи.
- Пунктуацию расставляет модель. Числа могут записываться цифрами; отдельного редактирования текста нет.
- Ошибка одного файла не останавливает обработку остальных. В конце выводится итог.
- Если очень тихая речь пропускается, попробуйте `--no-vad`. Для замены уже готового результата добавьте также `--overwrite`.
- Для полностью автономного запуска используйте `uv run --offline speech2text ...` после установки программы и модели.

## Если что-то не работает

| Сообщение или ситуация | Что сделать |
| --- | --- |
| `command not found: brew` | Установите Homebrew и выполните его **Next steps**. |
| `command not found: uv` | Выполните `brew install uv`. |
| Не найден `ffmpeg` или `ffprobe` | Выполните `brew install ffmpeg`. |
| Не найден проект или `scripts/setup.sh` | Перейдите в папку `speech2text` командой `cd`. |
| Модель отсутствует или повреждена | Повторите команду скачивания нужной модели из шага 3. |
| GigaAM не поддерживает `en` | Добавьте `--model whisper-large-v3`. |
| Результат уже существует | Укажите другую папку через `--output` или разрешите замену через `--overwrite`. |

Справка по всем параметрам:

```bash
uv run speech2text --help
```

Подробности для разработки: [устройство и проверки](docs/technical.md), [результаты тестирования](docs/validation.md).
